# 数字大冒险 MaxGate

从多条泳道里选出**数值最大**的那扇门。玩法接近 Temple Run 的左右变轨，核心却是限时心算与判断。

**[在线试玩 GitHub Pages](https://tanshilongmario.github.io/MaxGate/)**

当前仓库包含：

- 产品需求文档（PRD）
- 技术架构与扩展约定
- 难度曲线设计
- 可运行的竖屏 Three.js 积木世界原型

本地排名已落地；在线排行榜刻意不做，但数据模型按可上云方式预留。

---

## 一句话玩法

角色沿道路向前冲。前方同时出现 2–4 扇门，门上是数字或公式。在决策窗口内用键盘或滑动把角色移到**结果最大**的泳道。选对 +10 分，门短促闪烁后继续奔跑；选错扣 1 条命。三条命用尽结束。

开局可选「轻松 / 经典 / 冲刺」三种节奏。前 5 题只用于理解规则，第 6 题起按难度进入加减、乘除或两步计算。

## 快速开始

需要 Node.js 20+。

```bash
npm install
npm test
npm run dev
```

浏览器打开终端提示的本地地址。手机请竖屏访问同一局域网地址。

```bash
npm run build
npm run preview
```

## 操作

| 平台 | 操作 |
| --- | --- |
| 桌面 | `←` `→` 或 `A` `D` 换泳道 |
| 手机 | 左右滑动换泳道；竖屏游玩 |

判定发生在门到达角色时：以**当前所在泳道**结算，没有“空过免责”。

## 规则摘要

- 生命：3 条。后续可加肉鸽或回血，本版不加。
- 得分：每通过 1 扇门 +10。
- 难度：前 5 题教学，之后每 10 题升 1 段。三种节奏会调整时间窗、数值间隙和起始题型。
- 正确性：表达式由引擎求值，只允许唯一最大值（容差 `1e-9`），否则重掷。
- 排名：写入浏览器 `localStorage`。同一套 `RunRecord` 可在以后交给远程适配器。

## 为什么切换到 Three.js

玩法、题目和难度仍由原有 `Game` 状态机推进，Three.js 只接收 `FrameSnapshot` 渲染。切换后，门、道路、树木和角色都处在统一世界坐标中，透视由相机自然产生。道路使用连续底板，车道线和积木树通过对象池循环；远山、积木云和太阳组成随关卡进度由清晨过渡到黄昏的常亮天空。

## 仓库结构

```text
src/
  core/           随机数、时间、纯函数工具
  expressions/    公式 AST、求值、生成、展示
  difficulty/     关卡段位与曲线
  ranking/        本地缓存排名，预留远程适配器
  input/          键盘 + 滑动
  render/         渲染接口、Three.js 主实现与 Canvas 备用实现
  game/           状态机与一局循环
  ui/             菜单 / HUD / 结算
docs/             PRD、架构、难度曲线
```
