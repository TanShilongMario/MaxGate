# 数字大冒险 MaxGate

从多条泳道里选出**数值最大**的那扇门。玩法接近 Temple Run 的左右变轨，核心却是限时心算与判断。

当前仓库包含：

- 产品需求文档（PRD）
- 技术架构与扩展约定
- 难度曲线设计
- 可运行的竖屏网页原型（Canvas 2D，Three.js 按需接入）

本地排名已落地；在线排行榜刻意不做，但数据模型按可上云方式预留。

---

## 一句话玩法

角色沿道路向前冲。前方同时出现 2–4 扇门，门上是数字或公式。在决策窗口内用键盘或滑动把角色移到**结果最大**的泳道。选对 +10 分，门短促闪烁后继续奔跑；选错扣 1 条命。三条命用尽结束。

开局可选「轻松 / 经典 / 冲刺」三种节奏。前 5 题只用于理解规则，第 6 题起按难度进入加减、乘除或两步计算。

## 快速开始

需要 Node.js 20+。

```bash
npm install
npm test
npm run dev
```

浏览器打开终端提示的本地地址。手机请竖屏访问同一局域网地址。

```bash
npm run build
npm run preview
```

## 操作

| 平台 | 操作 |
| --- | --- |
| 桌面 | `←` `→` 或 `A` `D` 换泳道 |
| 手机 | 左右滑动换泳道；竖屏游玩 |

判定发生在门到达角色时：以**当前所在泳道**结算，没有“空过免责”。

## 规则摘要

- 生命：3 条。后续可加肉鸽或回血，本版不加。
- 得分：每通过 1 扇门 +10。
- 难度：前 5 题教学，之后每 10 题升 1 段。三种节奏会调整时间窗、数值间隙和起始题型。
- 正确性：表达式由引擎求值，只允许唯一最大值（容差 `1e-9`），否则重掷。
- 排名：写入浏览器 `localStorage`。同一套 `RunRecord` 可在以后交给远程适配器。

## 为什么第一版不用 Three.js

玩法成立不依赖 3D。第一版用 Canvas 2D 做透视跑道，包体小、手机更稳、竖屏好控。渲染层已抽出 `IRenderer`：需要角色动画、粒子、真实纵深时，再加 Three.js 实现，不必改规则与题目引擎。详见架构文档。

## 仓库结构

```text
src/
  core/           随机数、时间、纯函数工具
  expressions/    公式 AST、求值、生成、展示
  difficulty/     关卡段位与曲线
  ranking/        本地缓存排名，预留远程适配器
  input/          键盘 + 滑动
  render/         渲染接口与 Canvas 实现
  game/           状态机与一局循环
  ui/             菜单 / HUD / 结算
docs/             PRD、架构、难度曲线
```
